Before you start: use desktop Chrome, Edge, or Opera with a USB data cable. Show details
  • Browser Use desktop Chrome, Edge, or Opera. Firefox, Safari, and mobile browsers don’t support Web Serial.
  • Cable A USB data cable (not charge-only) plugged directly into your computer. Avoid hubs and long extensions.
  • Other apps Close anything else using the serial port (Arduino IDE, PlatformIO, ESPHome dashboard).
  • After flashing Keep the tab open — we’ll guide you through Wi-Fi setup over the same serial connection (Improv).

If your hub isn’t detected when you click Install, hold BOOT, tap RESET, then release BOOT to enter recovery mode and try again. Most devices don’t need this step.

Stable firmware · v1.0.0

Bathroom Bundle — PoE

Connect your Sense360 hub over USB and install the firmware for the kit you picked — right here in your browser.

  • Sense360 Core
  • RoomIQ room sensing
  • VentIQ bathroom air sensing
  • Power over Ethernet (PoE)

This is preview firmware — experimental and not the recommended choice for most customers. You’ll be asked to acknowledge the preview channel on the install step before it can be flashed.

This bundle drives a bathroom fan through the Sense360 Relay. You are responsible for the fan wiring and your local safety rules. It is preview firmware — not stable, not recommended, and not a customer default.

This bundle drives a 0–10V analog fan. The GP8403 analog fan driver must be switched so IC1 uses 0x58 and IC2 uses 0x5A. Address 0x59 must not be used, because the room air-quality sensor already uses it on the shared bus. This address setting has not been physically verified.

Advanced / manual warning

Sense360 TRIAC controls mains-connected loads and is not compliance-certified by WebFlash. It is not Release-One, not a kit / default option, and not recommended. No installable firmware has been imported yet. WebFlash will not install TRIAC firmware until an advanced/manual-warning artifact is imported. Use only if you understand the wiring, load, and local safety requirements.
